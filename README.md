# Raxae Frontend

Este é o frontend do projeto **Raxae**.

## Descrição

Raxae Frontend é uma aplicação web que serve como interface do usuário para o sistema Raxae.

## Tecnologias Utilizadas

- [React](https://react.dev/) (substitua caso use outra stack)
- [Vite](https://vitejs.dev/) (ou outro bundler/framework)
- [TypeScript](https://www.typescriptlang.org/) (opcional)
- [Styled Components](https://styled-components.com/) (ou outro CSS-in-JS/CSS framework)
- Outras bibliotecas...

> Atualize a lista acima conforme seu projeto.

## Instalação

Para rodar este projeto localmente, siga os passos abaixo:

```bash
git clone https://github.com/Anderson-Cardim/Raxae-frontend.git
cd Raxae-frontend
npm install         # ou yarn install
```

## Executando o Projeto

Para rodar o projeto em ambiente de desenvolvimento:

```bash
npm run dev         # ou yarn dev
```
